# Models

This directory is reserved for trained models and model configuration files.

Large model weights and checkpoints are intentionally excluded from GitHub.

The local project currently contains a trained LED (Longformer Encoder-Decoder) model for the ArXiv summarization experiments.

The model weights are approximately 3.4 GB and are stored outside this repository.

Future trained OCR, summarization, and translation models will be stored locally and excluded from Git when they are too large for normal Git version control.
